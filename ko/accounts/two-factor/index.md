# 2단계 인증

2단계 인증(2FA)을 활용해 Expo 계정을 보호하는 방법을 알아보세요.

2단계 인증은 expo.dev, Expo Go 앱, 그리고 명령줄 도구에 로그인할 때 추가 보안 계층을 제공합니다. 2단계 인증을 활성화하면 계정에 액세스하기 위해 사용자 이름과 비밀번호 외에 수명이 짧은 코드를 추가로 제공해야 합니다.

## 2단계 인증(2FA) 활성화

[개인 계정 설정](https://expo.dev/settings#two-factor-auth)에서 2단계 인증을 활성화할 수 있습니다.

## 2단계 인증 방법

인증 앱을 통해 2FA 코드를 받을 수 있습니다.

### 인증 앱

Expo는 Time-based One-time Passwords(TOTP)를 지원하는 모든 인증 앱을 허용하며, 여기에는 다음이 포함됩니다:

-   [Last Pass Authenticator](https://lastpass.com/auth/)
-   [Authy](https://authy.com/)
-   [1Password](https://support.1password.com/one-time-passwords/)
-   [Google Authenticator](https://support.google.com/accounts/answer/1066447)
-   [Microsoft Authenticator](https://www.microsoft.com/en-us/account/authenticator)

설정 과정에서 Expo가 인증 앱으로 스캔할 QR 코드를 제공합니다. 앱은 Expo에 입력할 확인 코드를 제공합니다. 인증 앱을 통한 2FA 활성화를 마치려면 이 코드를 입력하세요.

### SMS 메시지

> **사용 중단 예정:** 새로 추가되는 2단계 인증 방법에서는 더 이상 SMS가 지원되지 않습니다. 기존 SMS 2단계 인증 방법은 계속 동작하지만, 보안이 더 우수한 인증 앱으로 전환하는 것을 권장합니다.

SMS를 통해 수명이 짧은 토큰을 받으려면 휴대전화 번호를 입력하세요. SMS로 받은 코드는 최소 10분 동안 유효하므로, 이 시간 동안 동일한 코드를 여러 번 받을 수 있습니다. SMS 기기를 기본 2FA 방법으로 설정하면 2FA 코드가 필요한 작업을 수행할 때마다 확인 코드가 자동으로 전송됩니다.

### 복구 코드

계정에 2단계 인증을 설정하면 복구 코드 세트를 받게 됩니다. 인증 앱이나 SMS 기기에 접근할 수 없을 때 이 코드를 일회용 비밀번호 대신 사용할 수 있습니다. 각 복구 코드는 한 번만 유효하다는 점을 기억하세요.

복구 코드가 생성될 때 다운로드 옵션을 선택했다면, **expo-recovery-codes.txt**라는 이름의 파일에서 해당 코드를 찾을 수 있습니다.

> 복구 코드는 안전하고 기억하기 쉬운 장소에 보관해, 오직 본인만 계정에 접근할 수 있도록 하세요!

## 2단계 인증 설정 변경

[개인 계정 설정](https://expo.dev/settings)에서 2단계 인증 설정을 변경할 수 있습니다. 다음 작업을 할 수 있습니다:

-   인증 방법 추가 또는 제거
-   기본 방법 설정
-   복구 코드 재생성
-   계정의 2단계 인증 비활성화

2FA 설정을 변경하려면 일회용 비밀번호를 제공해야 합니다.

## 계정 복구

### 복구 코드

계정에 2FA를 설정하면 Expo가 복구 코드 목록을 제공합니다. 기기를 분실한 경우 복구 코드를 일회용 비밀번호 대신 사용할 수 있습니다. 각 코드는 한 번만 사용할 수 있습니다. [개인 계정 설정](https://expo.dev/settings/)에서 복구 코드를 다시 생성할 수 있으며, 이 경우 기존 코드는 모두 무효화됩니다.

### 보조 2FA 방법

서로 다른 물리적 기기에 연결된 여러 인증 방법을 설정하면, 기기가 초기화되거나 분실되더라도 계정에 대한 액세스를 잃지 않도록 할 수 있습니다.

### 수동 복구

제공된 어떤 방법으로도 계정에 접근할 수 없다면, 계정과 연결된 이메일 주소에서 [지원팀](https://expo.dev/contact)으로 이메일을 보낼 수 있습니다. 안타깝게도 이 경우 계정 액세스를 복구해 드릴 수 있다고 보장할 수는 없습니다.
