# Expo push notifications: 개요

Expo push notification service의 개요입니다.

Expo는 Firebase Cloud Messaging(FCM) 또는 Apple Push Notification Service(APNs)와 통신하는 데 필요한 복잡성의 상당 부분을 처리해 push notifications 구현을 단순화합니다. 덕분에 Android와 iOS 알림을 같은 방식으로 다룰 수 있으며, 프런트엔드와 백엔드 모두에서 시간을 절약할 수 있습니다.

아래의 영상이나 링크를 따라 push notifications를 설정하고, 전송하고, 앱에서 들어오는 알림을 처리하는 방법을 알아보세요.

[Expo Notifications with EAS | Complete Guide](https://www.youtube.com/watch?v=BCCjGtKtBjE) — Expo 프로젝트에서 push notifications를 설정하는 방법을 알아보세요. 이 영상은 Android에서 FCM v1용 Firebase 구성, EAS에서 Android 및 iOS credential 설정, EAS Build로 빌드하기, Expo Notifications 도구로 테스트하기까지 다룹니다.
