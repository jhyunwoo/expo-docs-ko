# 다음 단계

프로젝트를 개발하고, 검토하고, 제출하세요.

앱 빌드를 계속하기 위한 다음 단계는 다음과 같습니다:

### 프로젝트 초기화

boilerplate code를 제거하고 새 프로젝트로 다시 시작할 수 있습니다. 프로젝트를 초기화하려면 다음 명령을 실행하세요:

```sh
npm run reset-project
```

이 명령은 **app**의 기존 파일을 **app-example**로 옮긴 다음, 새로운 **index.tsx** 파일이 들어 있는 새 **app** 디렉터리를 만듭니다.

### 개발, 검토, 배포

Develop 섹션의 문서를 읽으며 개발하는 방법을 익혀 보세요. [UI elements](/develop/user-interface/splash-screen-and-app-icon)를 만들고, [unit tests](/develop/unit-testing)를 추가하고, [native modules](/config-plugins/introduction)를 포함하는 방법 등을 배울 수 있습니다.

앱 개발을 마쳤다면 팀원들과 [review](/review/overview)를 위해 공유할 수 있습니다.

마지막으로 프로젝트를 app store에 [build](/deploy/build-project)하고 [submit](/deploy/submit-to-app-stores)할 수 있습니다.

### 단계별 가이드

Expo로 앱을 처음부터 끝까지 빌드하는 과정을 안내하는 단계별 walkthrough가 필요하다면 [tutorial](/tutorial/introduction)을 확인해 보세요.
