# Release statuses

Expo SDK와 Expo Application Services(EAS)를 사용할 때 alpha, preview, beta, stable release status와 그것이 기능 안정성에 어떤 영향을 미치는지 알아보세요.

Expo는 도구와 서비스의 안정성과 준비 상태를 나타내기 위해 서로 다른 release status를 사용합니다. 이러한 status를 이해하면 프로젝트에서 어떤 기능과 버전을 사용할지 더 잘 판단할 수 있습니다.

## Alpha

Alpha 기능은 초기 테스트를 위해 제공되지만 상당한 제한이 있을 수 있습니다. 이러한 기능은 가장 초기 개발 단계에 있으며, 피드백을 수집하고 방향성을 정하기 위해 커뮤니티와 공유됩니다.

**예상할 수 있는 점:**

-   major version 증가 없이도 API가 깨지는 변경을 겪을 수 있습니다
-   피드백에 따라 구현이 크게 바뀔 수 있습니다
-   알려진 버그나 성능 문제가 있을 수 있습니다
-   프로덕션 앱에는 권장되지 않습니다

Alpha 기능은 Expo의 미래에 영향을 줄 기회입니다. 더 넓은 사용자층에 도달하기 전에 기능을 다듬을 수 있도록, 개발 환경에서 이 기능들을 테스트하고 [피드백을 제공](https://expo.dev/contact)해 주시기를 권장합니다.

## Preview

Preview 기능은 새로운 기능의 일부를 미리 보여 줍니다. alpha 릴리스와 달리 preview 기능은 최소한의 오버헤드와 제한된 범위로 설계되지만, 아직 기능이 완전히 갖춰진 상태는 아닙니다.

**예상할 수 있는 점:**

-   전체 기능 세트가 아닌, 특정 기능 조각에 초점을 맞춘 형태입니다
-   최소한의 오버헤드로 설계되었지만, 모든 프로덕션 시나리오에 대해 완전히 검증되지는 않았습니다
-   기능이 더 확장되면서 API가 계속 발전할 수 있습니다
-   철저한 테스트를 전제로 프로덕션에서 사용할 수 있지만, 기능 범위는 제한적입니다

Preview의 목적은 새로운 기능을 일찍 공유하고, 더 확장하기 전에 특정 기능 조각에 대한 피드백을 수집하는 것입니다. 여러분의 의견은 기능 방향을 직접적으로 결정하는 데 도움이 됩니다. 다음에 무엇을 만들지 우선순위를 정할 수 있도록 [피드백을 공유](https://expo.dev/contact)해 주세요.

## Beta

Beta 기능은 기능이 완성되어 있고 최종 검증을 진행 중입니다. 이러한 기능은 핵심 기능 구현이 끝났으며 stable release를 준비하고 있습니다.

**예상할 수 있는 점:**

-   핵심 기능은 완성되었고 API 형태도 대부분 확정되어 있습니다
-   해결 중인 사소한 버그나 edge case가 있을 수 있습니다
-   치명적인 문제가 발견되지 않는 한 깨지는 변경 가능성은 있지만 드뭅니다
-   철저한 테스트를 전제로 프로덕션에서 사용할 수 있습니다

Beta 기능은 실제 환경 테스트를 위한 준비가 된 상태입니다. 큰 변화는 예상하지 않지만, 프로덕션에서 사용할 계획이라면 충분히 테스트할 것을 권장합니다. 이 단계에서의 [여러분의 피드백](https://expo.dev/contact)은 stable release 전에 남은 문제를 잡는 데 도움이 됩니다.

## Stable

상태 배지가 없는 기능은 stable로 간주되며 프로덕션 사용을 위해 완전히 릴리스된 것입니다. 이러한 기능은 충분히 테스트되었고, 향후 변경 사항에 대해 semantic versioning을 따릅니다.

**예상할 수 있는 점:**

-   완전한 지원이 제공되는 프로덕션 준비 상태입니다
-   깨지는 변경은 major version 릴리스에서만 발생합니다
-   성능과 안정성이 검증되었습니다
-   문서와 예제가 제공됩니다

Stable 기능은 어떤 애플리케이션에서든 사용할 준비가 되어 있습니다. semantic versioning 원칙을 따른다고 믿고 사용할 수 있으며, 이는 깨지는 변경이 major version 업데이트에서만 일어난다는 뜻입니다.

## Deprecated

Deprecated 기능은 더 이상 사용이 권장되지 않으며 향후 릴리스에서 제거될 예정인 기능입니다. 개발자가 이 기능들에서 벗어날 시간을 가질 수 있도록 deprecation warning을 제공합니다.

**예상할 수 있는 점:**

-   deprecated 기능을 사용할 때 문서와 코드에서 경고가 표시됩니다
-   새로운 기능 추가나 개선은 이루어지지 않습니다
-   향후 major release에서 제거됩니다

Deprecated 기능을 마주쳤다면, 프로젝트를 최신 상태로 유지하고 유지보수 가능하게 하려면 가능한 한 빨리 권장 대안으로 마이그레이션할 계획을 세우는 것을 권장합니다.
