# 어디서나 실행되는 놀라운 앱을 만드세요

모든 사용자 기기에서 네이티브로 실행되는 하나의 JavaScript/TypeScript 프로젝트를 만드세요.

## 빠른 시작

```sh
npx create-expo-app@latest
```

그런 다음 [개발 환경 설정](/get-started/set-up-your-environment)을 계속 진행하세요.

## Android, iOS, 웹에서 동작하는 범용 앱 만들기

[튜토리얼 시작](/tutorial/introduction)

## 앱 스토어에 출시하기

설정이 전혀 없거나 사전 경험이 없어도 앱을 출시할 수 있습니다. Launch는 GitHub에서 바로 기술적인 부분을 쉽게 안내해 줍니다. 설정이나 사전 지식이 필요하지 않습니다.

[Launch 사용해 보기](https://launch.expo.dev/)

### CLI에서 배포하기

iOS와 웹 플랫폼용 명령줄 도구를 사용해 앱을 배포하세요.

## TestFlight에 배포하기

```sh
npx testflight
```

이 명령은 iOS 전용이며 앱을 TestFlight에 업로드합니다.

## 웹 앱 배포하기

```sh
npx eas-cli deploy
```

사전 요구 사항과 전체 지침은 [가이드](/deploy/web#export-your-web-project/)를 참조하세요.
