# Expo 및 React Native 앱에서의 데이터베이스

Expo 프로젝트에 데이터베이스를 추가하는 방법을 알아보세요.

대부분의 앱은 단일 세션의 수명을 넘어 데이터를 유지해야 합니다. 클라우드에 호스팅된 데이터베이스를 사용하면 앱의 데이터를 저장하고 기기와 사용자 전반에서 동기화할 수 있습니다.

## Convex

[Convex](https://www.convex.dev/)는 클러스터 관리, SQL, ORM이 필요 없는 TypeScript 기반 데이터베이스입니다. Convex는 WebSocket을 통해 실시간 업데이트를 제공하므로 반응형 앱에 특히 적합합니다.

[Convex 사용하기](/guides/using-convex) — Convex로 앱에 데이터베이스를 추가하세요.

## Supabase

[Supabase](https://supabase.com/)는 Postgres 데이터베이스, 사용자 인증, 파일 저장소, edge function, 실시간 동기화, vector 및 AI toolkit 같은 hosted backend 서비스를 제공하는 앱 개발 플랫폼입니다.

[Supabase 사용하기](/guides/using-supabase) — Supabase로 앱에 Postgres 데이터베이스와 사용자 인증을 추가하세요.

## Firebase

[Firebase](https://firebase.google.com/)는 실시간 데이터베이스, 클라우드 저장소, 인증, crash reporting, analytics 등 다양한 hosted backend 서비스를 제공하는 앱 개발 플랫폼입니다. Google 인프라 위에서 구축되어 자동으로 확장됩니다.

[Firebase 사용하기](/guides/using-firebase) — Firebase JS SDK와 React Native Firebase를 시작해 보세요.
