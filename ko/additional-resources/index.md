# 추가 리소스

Expo 도구와 서비스를 학습하는 데 유용한 리소스 참조입니다.

다음 리소스는 Expo 도구와 서비스에 대해 학습하는 데 유용합니다.

## 외부 리소스

### Expo 팀 소통 채널

-   [Blog](https://expo.dev/blog) - 공식 블로그입니다. 매달 릴리스 노트를 게시하고, 그 외 Expo 관련 콘텐츠도 수시로 올립니다.
-   [Changelog](https://expo.dev/changelog) - 공식 변경 로그입니다. EAS, 웹 대시보드, 기타 Expo 서비스 관련 변경 사항 정보를 수시로 게시합니다.

### GitHub

-   [expo/expo](https://github.com/expo/expo) - Expo Go, SDK, Docs, 그리고 Expo CLI입니다.
-   [expo/eas-cli](https://github.com/expo/eas-cli) - Android와 iOS 앱을 빌드, 제출, 업데이트하는 가장 빠른 방법입니다.
-   [expo/examples](https://github.com/expo/examples) - 통합 예제와 기타 예제들입니다.
-   [expo/config-plugins](https://github.com/expo/config-plugins) - 서드파티 패키지와 작업하기 위한 Expo Config Plugins입니다.
-   [expo/snack](https://github.com/expo/snack) - 브라우저에서 앱을 빌드합니다.
-   [expo/vscode-expo](https://github.com/expo/vscode-expo) - Expo 도구 작업을 위한 VS Code 확장입니다.
-   [expo/vscode-expo-theme](https://github.com/expo/vscode-expo-theme) - Expo 팀이 만든 VS Code 테마입니다.
-   [expo/fyi](https://github.com/expo/fyi) - Expo 도구와 서비스 문제 해결 가이드입니다.
-   [expo/orbit](https://github.com/expo/orbit) - macOS 메뉴 막대와 Windows 작업 표시줄에서 빌드를 실행하고 시뮬레이터를 시작합니다.
