[로그 보기](/workflow/logging) — 앱을 개발하는 동안 오류와 경고를 만났을 때 Expo CLI로 로그를 확인하는 방법을 알아보세요.

[macOS와 Linux에서 bundler cache 비우기](/troubleshooting/clear-cache-macos-linux) — macOS와 Linux에서 Expo CLI 또는 React Native CLI와 함께 Yarn 또는 npm을 사용할 때 bundler cache를 비우는 방법을 알아보세요.

[Windows에서 bundler cache 비우기](/troubleshooting/clear-cache-windows) — Windows에서 Expo CLI 또는 React Native CLI와 함께 Yarn 또는 npm을 사용할 때 bundler cache를 비우는 방법을 알아보세요.

["React Native version mismatch" 오류](/troubleshooting/react-native-version-mismatch) — React Native version mismatch가 무엇을 의미하는지와 Expo 또는 React Native 앱에서 이를 해결하는 방법을 알아보세요.

[프록시](/troubleshooting/proxies) — 권장 도구 모음과 함께 프록시를 troubleshooting하는 방법을 알아보세요.
