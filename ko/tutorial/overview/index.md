# 튜토리얼과 UI 가이드 개요

**Learn** 섹션은 Expo와 EAS를 학습하는 데 도움이 되는 튜토리얼과 기타 가이드를 모아 둔 컬렉션입니다. 다음 내용을 다룹니다:

[Expo Tutorial](/tutorial/introduction) — Expo가 처음이라면 이 튜토리얼부터 시작하는 것을 권장합니다. Android, iOS, 웹에서 실행되는 Expo 앱을 만드는 방법을 단계별로 안내합니다.

[EAS Tutorial](/tutorial/eas/introduction) — Expo Application Services(EAS)를 사용해 Android와 iOS 앱을 빌드하는 방법을 배우고 싶다면, 이 튜토리얼에서 EAS Build, Update, Submit 워크플로를 다룹니다.
