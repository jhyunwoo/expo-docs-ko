# Expo Application Services

Expo와 React Native 앱을 위한 Expo Application Services(EAS)를 알아보세요.

Expo Application Services(EAS)는 Expo 팀이 제공하는, Expo와 React Native 앱에 깊이 통합된 클라우드 서비스입니다.

자세한 소개는 [expo.dev/eas](https://expo.dev/eas)에서 확인하고, 시작 방법은 아래 링크를 따라가며 알아보세요.

[EAS Workflows](/eas/workflows/introduction) — CI/CD job으로 개발 및 릴리스 워크플로를 자동화하세요.

[EAS Build](/build/introduction) — 클라우드에서 custom 네이티브 코드를 포함한 Android/iOS 앱을 컴파일하고 서명하세요.

[EAS Submit](/submit/introduction) — 하나의 CLI 명령으로 클라우드에서 앱을 Google Play Store 또는 Apple App Store에 업로드하세요.

[EAS Hosting](/eas/hosting/introduction) — Expo Router와 React Native web 앱 및 API route를 배포하세요.

[EAS Update](/eas-update/introduction) — 작은 버그를 수정하고 빠른 수정 사항을 최종 사용자에게 직접 푸시하세요.

[EAS Metadata (preview)](/eas/metadata) — 앱을 게시하는 데 필요한 모든 app store 정보를 업로드하세요.

[EAS Insights (preview)](/eas-insights/introduction) — 프로젝트의 성능, 사용량, 도달 범위에 대한 analytics를 확인하세요.
