# EAS Workflows 제한 사항

현재 EAS Workflows의 제한 사항을 알아보세요.

EAS Workflows는 개발 및 릴리스 프로세스를 자동화하도록 설계되었습니다. 하지만 workflow 자동화 전략에 영향을 줄 수 있으므로, 앞으로 해결할 계획인 몇 가지 제한 사항을 알고 있는 것이 좋습니다.

## 공유 workflow 구성 없음

현재는 공유 workflow 구성을 정의할 수 없습니다. 각 workflow를 독립적으로 정의해야 하므로 일부 구성 중복이 생길 수 있습니다.

## Matrix 지원 없음

현재 EAS Workflows는 matrix build를 지원하지 않습니다. 즉 서로 다른 구성으로 같은 workflow의 여러 변형을 병렬 실행할 수 없습니다.
