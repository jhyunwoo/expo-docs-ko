# EAS Workflows 예제

앱을 개발, 리뷰, 릴리스할 때 사용할 수 있는 일반적인 React Native CI/CD workflow입니다.

다음 workflow들은 EAS Workflows를 사용해 개발, 리뷰, 릴리스 프로세스를 자동화하는 방법의 예시입니다. 이 workflow들은 팀과 함께 앱을 개발하고, 서로의 PR을 리뷰하며, 사용자에게 변경 사항을 지속적으로 릴리스하는 데 도움을 줄 수 있습니다.

### 예제

[Create development builds](/eas/workflows/examples/create-development-builds) — 각 플랫폼별 development build를 병렬로 시작하는 방법을 알아보세요.

[Publish preview updates](/eas/workflows/examples/publish-preview-update) — 모든 branch의 각 commit마다 preview update를 게시하는 방법을 알아보세요.

[Deploy to production](/eas/workflows/examples/deploy-to-production) — main에 merge할 때 앱 스토어에 build를 제출하거나 over-the-air update를 전송하는 방법을 알아보세요.

[Run E2E tests](/eas/workflows/examples/e2e-tests) — E2E 테스트를 실행하는 방법을 알아보세요.
