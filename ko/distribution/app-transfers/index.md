# App transfers

앱 소유권을 다른 주체로 이전하는 방법에 대한 개요입니다.

앱 소유권을 다른 주체에 넘길 때는 앱을 두 가지 관점에서 봐야 합니다. 하나는 Expo Application Services에서의 앱(EAS Build로 빌드를 만들고, EAS Update로 업데이트를 보내는 등)이고, 다른 하나는 app store의 앱 레코드(최종 사용자에게 앱을 배포하기 위한 것)입니다. 아래 가이드는 각각의 경우 앱 이전을 처리하는 방법을 설명합니다.

[EAS project transfers](/accounts/account-types#transfer-projects-between-accounts) — EAS project를 다른 Expo account로 이전하세요.

[Google project transfers](https://support.google.com/googleplay/android-developer/answer/6230247) — Android 앱을 다른 Google Play developer account로 이전하세요.

[Apple project transfers](https://developer.apple.com/help/app-store-connect/transfer-an-app/overview-of-app-transfer) — iOS 앱을 다른 Apple Developer account로 이전하세요.
