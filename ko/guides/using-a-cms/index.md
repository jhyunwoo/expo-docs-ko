# Content Management System(CMS) 사용하기

Expo 및 React Native 생태계에서 사용할 수 있는 Content Management System(CMS)의 개요입니다.

**Content Management System(CMS)** 는 사용자 정의 백엔드 코드를 작성하지 않고도 블로그 게시물, 이미지, 제품 정보 같은 디지털 콘텐츠를 만들고, 관리하고, 정리할 수 있게 해주는 플랫폼입니다. CMS를 사용하면 개발 시간을 크게 절약할 수 있고, 편집자나 마케터 같은 비기술 사용자도 사용자 친화적인 인터페이스를 통해 앱 콘텐츠를 쉽게 업데이트할 수 있습니다.

Expo 및 React Native 앱에 CMS를 통합하면 콘텐츠를 원격으로 관리하고 업데이트하고, 새로운 정보를 사용자에게 즉시 전달하며, 새 앱 업데이트를 배포하지 않고도 콘텐츠 운영을 확장할 수 있습니다.

Expo 및 React Native 프로젝트에서 고려할 수 있는 인기 있는 CMS 옵션은 다음과 같습니다:

[Strapi](https://strapi.io/integrations/expo) — Expo 앱에 Strapi를 통합하는 방법을 알아보세요.

[Sanity](https://www.sanity.io/docs/visual-editing/visual-editing-with-react-native) — Sanity 가이드로 Expo 및 React Native에서 Visual Editing을 구현하세요.
