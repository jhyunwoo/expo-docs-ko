# React Native analytics SDK와 라이브러리

Expo 및 React Native 생태계에서 사용할 수 있는 analytics 서비스의 개요입니다.

analytics 서비스는 사용자가 앱과 어떻게 상호작용하는지 추적할 수 있게 해줍니다. 이 데이터를 통해 앱을 개선할 때 더 측정 가능한 방식으로 접근할 수 있습니다.

아래 목록은 Expo 및 React Native 생태계에서 사용할 수 있는 일반적인 analytics provider를 제공합니다.

> 대부분의 analytics SDK는 custom native code 설정이 필요합니다. Expo Go를 사용할 때는 native code를 설정할 수 없습니다. 하지만 [development build](/develop/development-builds/introduction)를 만들면 아래 서비스들을 사용할 수 있습니다.

[Google Firebase Analytics](https://rnfirebase.io/analytics/usage) — 프로젝트에 React Native Firebase Analytics를 통합하는 방법을 알아보세요.

[Segment](https://segment.com/docs/connections/sources/catalog/libraries/mobile/react-native/) — 프로젝트에 Segment Analytics SDK를 통합하는 방법을 알아보세요.

[Amplitude](https://www.docs.developers.amplitude.com/data/sdks/typescript-react-native/) — 프로젝트에 Amplitude Analytics SDK를 통합하는 방법을 알아보세요.

[AWS Amplify](https://docs.amplify.aws/lib/analytics/getting-started/q/platform/react-native/) — 프로젝트에 AWS Amplify Analytics를 통합하는 방법을 알아보세요.

[Vexo](https://docs.vexo.co/) — 프로젝트에 Vexo Analytics를 통합하는 방법을 알아보세요.

[Aptabase](https://aptabase.com/for-react-native) — 프로젝트에 Aptabase Analytics를 통합하는 방법을 알아보세요. Expo Go에서 동작합니다.

[Astrolytics](https://www.astrolytics.io/react-native) — 프로젝트에 Astrolytics를 통합하는 방법을 알아보세요. Expo Go에서 동작합니다.

[PostHog](https://posthog.com/docs/libraries/react-native) — 프로젝트에 PostHog를 통합하는 방법을 알아보세요. Expo Go에서 동작합니다.

[Dreambase](https://dreambase.ai/docs) — Expo 및 Supabase 프로젝트에서 사용자 행동과 앱 성능을 추적하기 위해 Dreambase Analytics를 통합하는 방법을 알아보세요.
