# authentication SDK와 라이브러리 사용하기

Expo 및 React Native 생태계에서 사용할 수 있는 authentication 통합 개요입니다.

모바일 앱에서 authentication은 사용자가 누구인지 식별하고, 회원가입 또는 로그인 흐름을 관리하며, 앱을 다시 실행하거나 여러 기기에서 사용할 때도 인증된 세션을 유지하는 방식을 의미합니다. Authentication SDK와 라이브러리는 이러한 흐름을 추가하는 데 도움을 주므로, 직접 custom auth backend를 구축할 필요가 없습니다. 아래 가이드는 Expo 및 React Native 프로젝트에서 많이 쓰이는 SDK와 provider를 소개합니다.

> 일부 provider는 custom native code가 필요하며 Expo Go에서는 지원되지 않습니다. 필요할 때는 [development build](/develop/development-builds/introduction)를 사용하세요.

[Using Clerk](/guides/using-clerk) — Expo 및 React Native 프로젝트에 Clerk authentication과 사용자 관리를 추가하세요.

[Using Facebook authentication](/guides/facebook-authentication) — Expo 프로젝트에 Facebook authentication을 추가하기 위해 react-native-fbsdk-next를 설정하세요. — react-native-fbsdk-next

[Using Google authentication](/guides/google-authentication) — Expo 프로젝트에 Google authentication을 추가하기 위해 @react-native-google-signin/google-signin을 설정하세요. — @react-native-google-signin/google-signin
